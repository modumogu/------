# 靶标与坐标系约定

本文件是位姿链路的输入约定。改代码前先核对这里的尺寸、单位与坐标系定义。

## 靶标

- 黑色正方形，边长 **80.0 mm**，实心，无图案。
- 打印在 140 mm 见方的白色卡纸上，平放在桌面（标定板同一平面）。
- 正方形中心就是本任务要输出的**抓取点**。
- 正方形四条边外观相同，物理上具有 90° 旋转对称性，单看图像无法确定绝对朝向。本任务约定：**角点 0 取图像中 x+y 最小的那个角点**（画面里最靠左上角的一个），随后顺时针依次为 1、2、3（右上、右下、左下）；**角点 0→1 的方向为靶标 x 轴正方向**。绝对朝向以 `expected/` 样例为准，四个角点的编号必须与三维点表逐行对应。

## 坐标系

**靶标坐标系**（用于你写的三维点表）

- 原点：黑色正方形中心；
- `x` 轴：沿正方形一条边向右；
- `y` 轴：沿另一条边向上；
- `z` 轴：垂直靶面向外（指向相机一侧）；
- 单位：毫米。

**机械臂基坐标系**（用于输出的 `base`）

- `x` 轴：指向操作台前方；
- `y` 轴：指向操作台左侧；
- `z` 轴：垂直桌面向上；
- 原点：机械臂基座底面中心；
- 单位：毫米。

**相机坐标系**（`tvec_cam` 使用）

- 遵循 OpenCV 约定：`x` 向右、`y` 向下、`z` 沿光轴向前；
- 单位：毫米。

## 文件

| 文件 | 内容 |
| --- | --- |
| `calibration.yaml` | `camera_matrix`（3×3 内参）、`dist_coeffs`（畸变系数）、图像尺寸 |
| `handeye.yaml` | `T_base_cam`：相机坐标系 → 基坐标系的 4×4 齐次变换，平移单位毫米 |
| `pose_test.mp4` | 640×480、30 fps、240 帧；靶标始终完整可见，偏航角在 ±30° 内 |
| `calibration.mp4` | 640×480、30 fps、30 帧；标定板 10×7 个 25 mm 方格（内角点 9×6） |
| `frames/` | 从视频抽取的静帧，便于单帧调试 |

## 验收约定

- 所有计算都按 640×480 原图进行；不要把图像缩小后再做位姿计算。
- 输出的 `z` 在靶标平放时应接近 0 mm，允许几毫米的安装与测量误差。
- 偏航角 `yaw` 用 `atan2(R[1,0], R[0,0])` 计算，单位度，范围 (-180, 180]。
